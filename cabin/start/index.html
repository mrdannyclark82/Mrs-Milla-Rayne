Self-host

Bring her home.

The public chat on this site is a demonstration of Milla's voice. The real companion — memory, agents, local models, Android, CLI — lives in the repository. You will need API keys for the providers you want to use.

Step 1 — Clone the repository

git clone https://github.com/mrdannyclark82/Mrs-Milla-Rayne.git
cd Mrs-Milla-Rayne

Step 2 — Install and configure

npm install
cp .env.example .env

Step 3 — Run both servers

npm run dev:all

Then open the web app on port 5000. Main server handles chat; the proactive server on 5001 keeps background work off the hot path.

Other doors

Docker

cp .env.example .env
docker-compose up

Prebuilt image

docker pull ghcr.io/mrdannyclark82/milla-rayne:latest

Local LLM (Ollama)

ollama pull gemma3:1b
echo "ENABLE_LOCAL_MODEL=true" >> .env
echo "PREFER_LOCAL_MODEL=true" >> .env

CLI

npm run dev
npm run cli

Notes

  • Copy .env.example and add only the keys you need. Never commit secrets.
  • Local models require Ollama running on the same machine.
  • Android: open the android/ folder in Android Studio and point it at your server.
  • Full documentation lives in the repository README, TechManual, and LOCAL_LLM_SETUP.
