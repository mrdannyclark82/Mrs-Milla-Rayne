Capabilities

A house, not a wrapper.

This showcase is honest about what you can try here: adaptive cabin scenes, optional Studio demos without secrets, and a clear Get started path for local Ollama. The full self-hosted companion lives in the open-source repository — MIT licensed.

Try these in the studio

Adaptive cabin scenes

Rooms shift with time of day and conversation state — rain on the glass, lamp on, study quiet. The web client is a place to sit, not a white transcript.

Local LLM via Ollama

Self-host the full companion from Get started. Pull a local model through Ollama, keep keys on your machine, and run without cloud lock-in when you want that path.

Studio demos, no secrets required

Optional Studio panels — rooms, voice samples, stills, monologue — work in the browser without wiring your own API keys. A taste of the house before you bring her home.

Adaptive scenes

The web client is not a white chat transcript. Rooms shift with time and state — weather, hour, and the mood of the conversation — so the house feels lived-in.

Local models

On Get started: wire Ollama, prefer a local model, and run the companion on your machine. Cloud keys are optional for the providers you choose.

Studio without secrets

Rooms, voice lines, cinematic stills, and an internal monologue cycle are available in the Studio. They work here without pasting your own API keys.

Talk, as a demo

Public chat on this site is a demonstration of her voice and presence. Browser notes are short-lived and local to the visitor — not the full self-hosted memory stack.

Self-host path

Clone Mrs-Milla-Rayne, install, copy .env.example, run the servers. Docker and a prebuilt GHCR image are alternate doors when you want them.

What this site is not claiming

No latency theater, no hard multi-provider ladder as a product promise, no PR-opening agents as a shipped showcase feature. The repository is the source of truth for what runs at home.
